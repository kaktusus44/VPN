# Смена IP работающего VPN

На управляющей Ubuntu обновите репозиторий и запустите:

```bash
cd ~/VPN
git pull --ff-only
scripts/rotate-endpoint
```

Укажите роль `main`/`reserve`, доступный сейчас SSH IPv4 и прежний SSH IPv4
(Enter, если он не менялся). Затем выберите входной и выходной IPv4.
Можно изменить только один адрес, оставив другой прежним. `auto` для выхода
возвращает выбор исходящего адреса операционной системе.

Новый SSH IP должен быть доступен заранее. Если выбранный VPN IP ещё не настроен
в ОС, скрипт предложит добавить его как `/32`: подтверждайте только адрес,
уже прикреплённый у хостера. Основной маршрут и старые адреса не удаляются.

Роль `vpn_readdress` обновляет существующие конфигурации Xray, NAT AmneziaWG,
исходящий адрес DNS, клиентские профили и ссылки. При смене SSH IP обновляются
связанные настройки мониторинга и известные узлы из сохранённого inventory.
Если второй узел отсутствует в inventory, укажите его через `VPN_MAIN_IP`
или `VPN_RESERVE_IP` и повторите команду, указав прежний SSH IP.

Ключи и UUID сохраняются. Перезапускаются только сервисы с изменёнными
конфигурациями; смена только входного IP не требует перезапуска VPN.
Резервные копии находятся на VPS в `/var/lib/vpn/ip-change-backups/`.
При ошибке применения роль пытается восстановить прежние файлы и сервисы.

Обновлённые клиентские файлы сохраняются в `exports/<текущий SSH IP>/`.
В выводе — пути Amnezia и две ссылки Xray. При смене входного IP импортируйте
профили заново; при смене выходного IP переподключите клиентов, чтобы старые
соединения не продолжали использовать прежний NAT.
